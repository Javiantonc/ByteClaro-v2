# ByteClaro — guía práctica para principiantes

## Archivos principales
- `index.html`: página principal.
- `styles.css`: colores, diseño y adaptación a móviles.
- `script.js`: productos de ejemplo, menú móvil y comparador.
- Las páginas legales son plantillas que debes adaptar.

## Abrir en tu ordenador
Descarga o clona el repositorio y abre `index.html` en el navegador. No necesitas instalar Node.js ni paquetes: esta versión utiliza HTML, CSS y JavaScript sin dependencias.

## Añadir productos
Edita el array `products` en `script.js` y escribe descripciones originales y características verificadas. No inventes precios, valoraciones ni disponibilidad. Añade enlaces especiales válidos solo cuando dispongas de ellos; los botones de esta demo permanecen desactivados.

## Publicar gratis con GitHub Pages
1. En el repositorio, abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`; guarda.
4. Espera a que GitHub muestre la URL publicada y comprueba la web.

Revisa las condiciones vigentes de Amazon Afiliados España: https://afiliados.amazon.es/help/operating/policies/ . Completa las páginas legales según tu situación real. Esta demo no integra IA, base de datos ni API de Amazon y no garantiza aprobación ni ingresos.
