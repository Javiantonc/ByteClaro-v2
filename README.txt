BYTECLARO — PROYECTO INICIAL DE AFILIADOS

Web responsive en HTML, CSS y JavaScript sin dependencias.

Archivos principales:
- index.html: estructura de la web.
- styles.css: diseño visual y adaptación a móviles.
- script.js: productos de ejemplo y comparador.
- GUIA-PASO-A-PASO.md: instrucciones para editar y publicar.

Los productos son ejemplos y los botones de compra están desactivados hasta añadir enlaces especiales válidos de afiliado. Las páginas legales son plantillas que debes adaptar antes de publicar. No hay integración real con IA, base de datos ni API de Amazon.
