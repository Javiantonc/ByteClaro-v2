BYTECLARO — COMPARADOR DE PRECIOS

Interfaz responsive para buscar productos y comparar ofertas de tiendas usando una API real, una vez aprobada y configurada.

ARCHIVOS
- index.html: página y formulario de búsqueda.
- styles.css: diseño responsive.
- script.js: consulta API y presentación de resultados.
- netlify/functions/search.mjs: proxy de servidor para proteger la clave.
- netlify.toml: rutas y configuración de Netlify.
- GUIA-PASO-A-PASO.md: pasos de configuración.

IMPORTANTE
La integración consulta Comparaloo a través de una función de Netlify. La API requiere solicitud y aprobación; hasta configurar COMPARALOO_API_KEY en las variables de entorno de Netlify, no habrá resultados reales. Nunca pongas la clave en archivos públicos ni en GitHub.
Los precios y la disponibilidad dependen de los datos de la fuente y pueden cambiar. La cobertura no incluye necesariamente todas las tiendas de España. Revisa las condiciones y la atribución exigida por el proveedor.
